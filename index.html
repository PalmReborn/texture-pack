Three steps

How to install

Takes about a minute. You only do it once.

01

Download

Press Download. You get a file called Cobra Kitmap.zip. Leave it zipped.

02

Open the pack folder

In Minecraft go to Options Resource Packs Open Resource Pack Folder and drop the zip in.

03

Turn it on

Back on the Resource Packs screen, move Cobra Kitmap to the right side and press Done.

Even easier: just join. The server offers the pack when you connect. Say Yes and you are done. In game, /pack sends you the download link again.

Good to know

Questions

I installed it but my armor still looks normal

The custom looks need OptiFine. Lunar Client and Badlion Client have it built in. On plain Minecraft the pack still loads, but the armor looks the same as before.

Do I have to install it by hand?

No. When you join, Minecraft asks if you want the server's pack. Say Yes. If you said No before, select the server in your list, press Edit, and set Server Resource Packs to Enabled.

Does it change my other textures?

No. It only changes the custom armor sets, the Diamond Hook and enchant runes. Blocks, normal items and your own PvP pack stay exactly as they are.

Can other players see my set?

Yes. Everyone who has the pack sees the colors of your set, and you see theirs.

Which Minecraft version is it for?

Minecraft 1.8, the version the server runs on.
